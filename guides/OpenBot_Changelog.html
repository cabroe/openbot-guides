Release-Übersicht von 0.50.0 (Okt 2026) bis 0.72.0 (Nov 2026) — was sich geändert hat, was neu ist und welche Breaking Changes beim Upgrade beachtet werden müssen.

0.72.0Aktuelle Version
126Releases total
Aug 2026Erster Release

NeuVersion 0.72.0 — 16. November 2026

Aktion erforderlich: Phone-App und alle verbundenen Server müssen auf 0.72.0 aktualisiert werden, damit Bug-Reports Versionsinfos enthalten. Wenn eine Website wie X einen Server-Sign-in ablehnt, erscheint jetzt eine Aufforderung, sich stattdessen über die Desktop-App anzumelden.

Das bisher umfangreichste Release: 58 neue Features, 43 Verbesserungen, 259 Bugfixes — plus zwei Entfernungen.

Highlights New (Auswahl)
New
  • Geteilte Browser-Profile für Agents mit Freigabe-Karten
  • Connectors für AppSignal, Cloud 66, HubSpot und Stripe CRM
  • WhatsApp: 90-Tage-Nachrichtenverlauf + Dateisuche
  • CRM-Seite für Owners und Admins (experimentell, standardmäßig aus)
  • Bibliothek mit Favoriten, Ordner-Kacheln und „Zuletzt geöffnet"
  • Animierte Hintergründe, auch agent-generiert
  • Sprachnachrichten per Enter absenden
  • Umbrel-Installationspfad und Setup-Seite für Docker-Images
  • Chat-Blasenfarben folgen dem Agent-Avatar
  • Größere VPS-Storage-Tiers verfügbar
Verbessert Improved (Auswahl)
Improved
  • Remote Desktop auf Cloud- und Docker-Servern zeigt OpenBot-Desktop
  • macOS nutzt die SF Pro Systemschrift
  • Neu strukturierte Settings-Seite mit einem eigenen Memory-Bereich
  • Agents probieren eigene Tools, bevor sie nach einer App-Verbindung fragen
  • Code-Blöcke und breite Tabellen scrollen jetzt horizontal
  • Tempo-Markierungen an Plan-Limit-Balken
Entfernt Removed
Breaking
  • Plan eines gehosteten Servers lässt sich nicht mehr ändern
  • MCP-Sign-in auf verbundenen Servern, die keine Sign-in-Seiten weiterleiten, entfernt

TrendsEntwicklungsschwerpunkte

Ein Blick auf die Muster hinter den Releases: Was OpenBot zwischen August und November 2026 systematisch aufgebaut hat.

🔊
Voice & Audio
Gesprochene Antworten (ElevenLabs, xAI), Groq Whisper, Custom Voice Server, Eleven v4 — Voice-Features wurden in rascher Folge aufgebaut.
🖥️
Cross-Platform
Linux-Dock, Windows Dynamic Island, macOS SF Pro — jede Plattform bekommt systematisch das Feature-Set der anderen.
🔄
Workflows
Von einfachen Routinen zu vollständigen Workflow-Engines mit Bedingungen, Schleifen, Channel-Outputs und Trigger-Integrationen (GitHub, Slack, Discord).
🔐
Sicherheit & Zugriff
Vault, MCP-Zugriff pro Agent, Remote-Desktop-Kontrollen, OpenID Connect, Audit-Log — Sicherheitsfundament schrittweise aufgebaut.
🧩
Provider-Vielfalt
Mistral, Devin, GitHub Copilot, Kimi, Hermes, Groq, DeepSeek — das Provider-Ökosystem wächst kontinuierlich; jeder bekommt eigene Steuerung.
📱
Mobile & Dock
Agent-Dock auf macOS, Windows und Linux; Dynamic Island; Mobile-App-Verwaltung für Server-Einstellungen — OpenBot bewegt sich aus dem Fenster heraus.
🌍
Internationalisierung
Arabisch, Hebräisch, Niederländisch, Koreanisch, Chinesisch (vereinfacht), Polnisch, Brasilianisches Portugiesisch — breite Sprachunterstützung in kurzer Zeit.
🧠
Skill-System
Agents lernen und überarbeiten eigene Skills, importieren aus GitHub-Repos, und ein eigener Usage-Tab misst Skill-Kosten. Skills werden zur Kerninfrastruktur.
Hinweis zur Vollständigkeit: Dieser Guide deckt Releases 0.50.0–0.72.0 ab (Oktober–November 2026). Die früheren Releases ab 0.1.0 (August 2026) sind auf openbot.run/changelog vollständig dokumentiert.
