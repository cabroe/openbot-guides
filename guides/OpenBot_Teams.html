OpenBot für Teams

Gemeinsame Agent-Umgebungen für Firmen, Agenturen und Remote-Teams — von der einfachen Shared-Server-Einrichtung bis zur vollständig individuell konfigurierten Deployment-Lösung.

01Drei Setup-Optionen

OpenBot bietet Teams drei Wege, eine gemeinsame Umgebung zu betreiben. Der Unterschied liegt im Hosting und im Support-Umfang:

🏠
Lokal
Einzelne Personen oder kleine Teams betreiben OpenBot auf ihrer eigenen Infrastruktur. Vollständige Kontrolle, keine monatlichen Hosting-Kosten, aber eigene Wartung.
☁️
Managed Server
Empfohlen für Teams
Der Anbieter hostet und wartet den Server. Agents, Automatisierungen und Personen teilen sich eine gemeinsame Umgebung — rund um die Uhr verfügbar, ohne eigene Infrastruktur.
🏢
Custom Deployment
Das Unternehmen konfiguriert Umgebungen, Agents, Berechtigungen und Integrationen individuell rund um bestehende Workflows. Für Firmen mit speziellen Anforderungen.
Wichtig: Beim Managed Server laufen Agents, Automatisierungen und Personen in einer gemeinsamen Umgebung. Cloudflare verwaltet Konten und Einladungen — Chats, Dateien und Befehle bleiben ausschließlich auf dem lokalen Server.

02Team-Features im Überblick

Diese Kernfunktionen machen OpenBot für Teams attraktiv:

🕐
24/7-Agents
Auf Managed-Infrastruktur laufen Agents kontinuierlich — auch nachts, an Wochenenden und wenn das Team offline ist.
🔄
Geplante Automatisierungen
Routinen können zeitgesteuert ausgeführt werden — zu definierten Zeiten oder mit festgelegten Intervallen, ohne manuelle Auslösung.
👥
Multiplayer-Kollaboration
Personen und KI-Mitarbeiter teilen sich einen Server. Channels, Threads und Delegierung ermöglichen koordinierte Team-Arbeit.
📱
Remote-Zugriff
Verbindung vom Desktop oder Mobilgerät. Owner und Admins können Agent-Einstellungen direkt aus der Mobile-App verwalten.

Zugriffs- und Sicherheitsfeatures für Teams

  • Rollen: Owner, Admin und Mitglied mit unterschiedlichen Berechtigungen
  • MCP-Zugriff per Agent: Jeder Agent bekommt nur die MCP-Server und Apps, die er braucht
  • Vault: Verschlüsselter Speicher für Logins, API-Keys, Zahlungskarten und Kontakte — Zugriff per Agent konfigurierbar
  • Audit-Log: Nachvollziehbares Protokoll aller Server-Aktionen für Owner und Admins
  • OpenID Connect: Firmen-Anmeldung über bestehende Identity-Provider
  • Thread-Parallelitätslimits: Pro Server und pro Agent konfigurierbar
  • Channel-Browserrechte: Welche Mitglieder den eingebetteten Browser nutzen dürfen
Team-Einladungen: Personen werden über WebRTC zu einem bestehenden Server eingeladen. Die Team-API bleibt auf Loopback; Cloudflare überträgt nur Setup-Nachrichten, keine Chats oder Befehle.

03Implementation Services (Custom)

Für Unternehmen mit komplexen Anforderungen bietet OpenBot einen vollständig begleiteten Deployment-Prozess:

1
Infrastruktur-Setup und Konfiguration
Einrichtung der Server-Umgebung auf eigener oder verwalteter Infrastruktur, abgestimmt auf bestehende IT-Landschaft und Sicherheitsanforderungen.
2
Initiale Agent-Konfiguration
Agents werden für spezifische Rollen, Workflows und Zugriffsrechte konfiguriert — mit passenden Skills, Apps und Instruktionen.
3
Integration mit bestehenden Tools
Anbindung an interne Systeme, Datenquellen und bestehende Toolchains — über die Marketplace-Apps oder Custom-Integrationen.
4
Custom Features und Workflows
Entwicklung individueller Workflows, Automatisierungen und Features, die über den Standard-Funktionsumfang hinausgehen.
5
Laufende Wartung und Weiterentwicklung
Kontinuierlicher Support, Updates und Anpassungen nach dem initialen Deployment — für Unternehmen, die keine eigene OpenBot-Expertise aufbauen wollen.

Das Custom-Deployment-Modell richtet sich an Unternehmen, die Agents abteilungsübergreifend einsetzen, Agenturen, die Agent-Umgebungen für Kunden aufbauen, sowie Organisationen mit spezifischen Datenschutz- oder Compliance-Anforderungen.

05Erste Schritte für Teams

Option A: Managed Server einrichten

  1. Öffne Settings → Server und wähle Hosted Server erstellen
  2. Wähle einen Hosting-Standort und einen Speichertier
  3. Lade Teammitglieder über Settings → Mitglieder → Einladen ein
  4. Vergib Rollen: Owner, Admin oder Mitglied
  5. Konfiguriere Agent-Defaults unter Server-Einstellungen → Agents

Option B: Eigenem Server beitreten

  1. Der Server-Owner schickt einen Einladungslink
  2. Öffne OpenBot → Server beitreten und gib den Einladungscode ein
  3. Verbindung läuft über WebRTC — kein direkter Netzwerkzugang zum Server nötig

Empfohlene Ersteinrichtung für Teams

  • Richte einen Firmen-Agent ein, der als Kontext-Halter für firma-weite Informationen dient
  • Aktiviere den Audit-Log von Anfang an — rückwirkende Logs gibt es nicht
  • Konfiguriere MCP-Zugriffsrechte pro Agent, bevor du produktive Agents startest
  • Lege API-Keys im Vault ab statt in Agent-Instruktionen
  • Nutze Channels für abteilungsübergreifende Kommunikation mit Agents
