01Was sind Apps in OpenBot?

Im OpenBot-Marketplace werden unter dem Tab Apps Plugins aufgelistet, die ein Agent aktiv nutzen kann. Jede App erweitert den Agent um neue Fähigkeiten: Er kann damit auf externe Dienste zugreifen, Daten abrufen, Aktionen auslösen oder Inhalte erstellen — alles ohne Browser-Umweg.

Der Unterschied zu Skills: Skills beschreiben, wie ein Agent denkt und handelt (Schreibstil, Struktur, Rollenverhalten). Apps beschreiben, womit er handelt — konkrete Verbindungen zu Figma, Notion, Supabase, Stripe und Hunderten weiterer Dienste.

Wichtig: Apps laufen auf deinem eigenen Computer. OpenBot kennt keine Chat-Verläufe oder Befehle — es stellt nur die Verbindung zwischen Agent und Dienst her. Zugangsdaten bleiben bei dir.

Was eine App technisch tut

Jede App stellt dem Agent eine Menge von Tools zur Verfügung — strukturierte Funktionen, die der Agent im Kontext einer Aufgabe aufrufen kann. Eine Notion-App hat zum Beispiel Tools wie „Seite erstellen", „Datenbank abfragen" oder „Block aktualisieren". Der Agent entscheidet selbst, welches Tool er wann einsetzt.

Apps erscheinen im Marketplace mit einer Versionsnummer (z. B. v1.1.1), damit du immer weißt, welchen Stand du installiert hast und ob Updates vorliegen.

04Zapier & Composio — die Brücken-Apps

Zwei Apps im Marketplace heben sich durch ihre Reichweite heraus: Sie verbinden OpenBot-Agents nicht mit einem einzelnen Dienst, sondern mit Hunderten gleichzeitig.

Composio
1 000+ integrierte Dienste
Composio ist eine Integrations-Plattform, die standardisierte Tools für über 1 000 Apps bereitstellt. Einmal installiert, kann dein Agent auf Dienste zugreifen, die keinen eigenen Marketplace-Eintrag haben — von Slack bis Salesforce bis GitHub.
Zapier
Aktionen in verbundenen Apps auslösen
Mit dem Zapier-Plugin kann ein Agent Zaps (Automatisierungen) auslösen, die du in Zapier konfiguriert hast. Dein Agent muss die Ziel-App nicht direkt kennen — er gibt nur einen Trigger an Zapier weiter.

Wann welche Brücke?

  • Composio eignet sich, wenn du direkte Tool-Calls brauchst: der Agent soll eine Aktion in einem Dienst ausführen, und Composio liefert das passende Tool zur Laufzeit.
  • Zapier eignet sich, wenn du bestehende Automatisierungen weiterverwenden willst: du verwaltest die Logik in Zapier, der Agent löst nur aus.
  • Beide zusammen: Zapier für komplexe Multi-Step-Flows, Composio für direkte Einzelaktionen in spezifischen Diensten.
Composio und Zapier ersetzen keine nativen Apps — sie ergänzen sie. Wenn Figma oder Supabase im Marketplace verfügbar sind, nutze die native App: sie ist spezialisierter und hat weniger Overhead.

05Erste Schritte: Apps installieren und nutzen

So richtest du eine App für deinen Agent ein:

1
Marketplace öffnen
Navigiere in OpenBot zum Marketplace und wechsle auf den Tab Apps. Du kannst nach Kategorie filtern oder über die Suche direkt nach einem Dienst suchen.
2
App auswählen und installieren
Klicke auf die gewünschte App und wähle Installieren. Bei Diensten, die Authentifizierung brauchen (Notion, Stripe usw.), wirst du nach einem API-Schlüssel oder OAuth-Login gefragt.
3
App einem Agent zuweisen
Öffne den Agent, dem die App zur Verfügung stehen soll. Unter den Agent-Einstellungen findest du den Bereich Apps — aktiviere dort die installierte App. Der Agent kann nur Tools nutzen, die explizit zugewiesen wurden.
4
Im Gespräch nutzen
Starte eine Unterhaltung mit dem Agent. Er entscheidet selbst, welche App-Tools er für deine Aufgabe einsetzt. Du kannst ihn auch explizit ansprechen: „Erstelle eine Notion-Seite mit dem Ergebnis."
5
Updates im Blick behalten
Apps erscheinen im Marketplace mit einer Versionsnummer. Wenn eine neue Version verfügbar ist, siehst du einen Update-Hinweis — bestehende Konfigurationen bleiben dabei erhalten.

Empfehlung für den Einstieg

Starte mit einer App, die einen Dienst abbildet, den du täglich nutzt — Notion, Linear oder Supabase sind gute erste Kandidaten, weil sie breite Tool-Sets haben und gut dokumentiert sind. Installiere Composio erst dann, wenn du auf einen Dienst angewiesen bist, der keinen eigenen Marketplace-Eintrag hat.

Tipp: Teste neue Apps zunächst in einem dedizierten Test-Agent, bevor du sie deinen produktiven Agents gibst. So kannst du das Verhalten beobachten, ohne bestehende Workflows zu stören.
